Subtitle Maker & Translator

Free, open-source subtitles for your Mac. Transcribe locally and optionally translate with your ChatGPT plan. This is a local support draft; live authentication verification and public hosting are pending.

Get started

  1. Download a speech model from setup. The store version already includes FFmpeg, FFprobe and Whisper.
  2. Add a video or audio file and authorize its folder for subtitle output. Choose the spoken language or automatic detection.
  3. For translation, use Continue with ChatGPT, authorize plan usage, choose an available model and select translation languages. Leave all translation languages unchecked to transcribe without login.
  4. Start processing. Save SRT subtitles or embed them in a supported video container.

The direct-distribution version uses first-run executable downloads and separately installed, signed-in Claude Code or Codex CLI for translation.

Requirements

macOS 14 or later and an Apple Silicon Mac. The current interface is in Korean. Downloads require an internet connection and sufficient disk space. Translation also requires a compatible account and plan with the selected provider.

If a task fails

Read the error beside the file. Check disk space, the speech model and folder authorization. If ChatGPT usage reaches a limit, choose Manage usage, review the limit, then refresh the model list to retry when usage is available. Reconnect an expired account with Continue with ChatGPT. A translation failure keeps source subtitles; embedding failures preserve generated SRT files.

Before sharing a diagnostic report

Include your app version, macOS version, Mac model, and the steps that reproduce the problem. Remove private paths, subtitle text and account information from screenshots or logs.
