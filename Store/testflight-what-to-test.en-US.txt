Please test transcription and subtitle translation on an Apple Silicon Mac running macOS 14 or later. The current interface is in Korean.

1. Select a speech model that has not been installed, authorize a disposable test-media folder, and start transcription. The app should download the model automatically, show downloaded bytes/total size, then continue transcribing. Check the rotating activity indicator, transcribed audio/total time, estimated decoder progress and chunk number. Existing valid source SRT or embedded text subtitles should bypass model downloads.
2. Subtitle timing (new in build 5): transcribe a video with music or silence before the first line. Cues should appear when speech starts, not at 0:00 or during preceding music. The speech-detection (VAD) model now installs with the speech model; if it cannot be installed, transcription should stop with a message instead of producing early subtitles. Subtitles already embedded by an earlier build are not regenerated automatically.
3. Reopen the app and check that the authorized folder and queue still work. Confirm that SRT files are saved next to the media.
4. Change the transcription language, translation targets or subtitle output mode after a completed job. The file should return to Pending and its previous progress should clear. Existing files should remain.
5. Apple Translation (new in build 6, macOS 26+): choose 번역 방식 → Apple 번역 (기기 내), set the spoken language, select a target language and start. Approve the macOS download prompt if shown. Translated SRT numbering and timings must match the source. With automatic language detection, a missing language pack should trigger the macOS download prompt right before translation (the Dock bounces if SubGen is in the background); after you approve, that file waits for the download and then translates. Declining should fail only that translation and keep the source subtitles.
6. Continue with ChatGPT, select your account, then approve ChatGPT plan usage and click Continue if you wish to test translation. The app now waits up to 30 minutes for this final consent and shows these steps while connecting. Verify the account's available model list and a short English-to-Korean SRT translation. Translation uses your ChatGPT plan/credits and may be limited by account availability or usage limits. Transcription works without signing in.
7. During translation, check the accepted subtitle count and chunk indicator. Test cancellation, sign-out and a network interruption; failed work should preserve existing source subtitles.
8. On disposable copies of MP4/MOV/MKV/WebM videos, select video subtitle output, test subtitle embedding and verify playback. Blank or zero-duration recognizer segments should be omitted without failing the entire chunk. Genuine malformed timings should show the cue number and preserve a diagnostic SRT next to the media when folder access permits. The app replaces the input video after validating the output, so use copies for beta testing.

Live ChatGPT authentication/inference, folder permission reuse across relaunch and visual animation are pending distributed-build verification. Please report the stage, error message and macOS version without sharing account credentials or private media.
