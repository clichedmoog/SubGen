SubtitleGen third-party tools

These executables are invoked as separate command-line processes.

FFmpeg and FFprobe
  ARM64: FFmpeg 9.0, OSXExperts static build
  Intel: FFmpeg 8.0, OSXExperts static build
  Binary distributor: https://www.osxexperts.net/
  Project and source releases: https://ffmpeg.org/download.html
  ARM64 upstream source: https://ffmpeg.org/releases/ffmpeg-9.0.tar.xz
  Intel upstream source: https://ffmpeg.org/releases/ffmpeg-8.0.tar.xz
  These builds enable GPL components. See FFmpeg-GPLv2.txt and
  FFmpeg-GPLv3.txt. Run ffmpeg -L and ffmpeg -buildconf for the actual
  license statement, enabled components and build configuration.
  Distributor builds include third-party codec libraries; the upstream
  FFmpeg source alone does not contain those libraries or build recipes.

  This package builds static libraries with embedded Metal kernels,
  macOS deployment target 14.0 and GGML_NATIVE=OFF.

Claude Code and Codex CLI are not bundled.
